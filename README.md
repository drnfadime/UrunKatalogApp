🛒 Ürün Kataloğu Uygulaması
Bu proje, React Native eğitimim kapsamında geliştirdiğim ilk mobil uygulama projemdir. Temel mobil uygulama geliştirme mantığını, bileşen yapısını ve veri yönetimini kavramak amacıyla hazırlanmıştır.

🚀 Öne Çıkan Özellikler
Ürün Listeleme & Detay: Dinamik ürün listesi ve her ürüne özel detay sayfası.

Anlık Arama: Ürünler arasında isim bazlı filtreleme.

Favori Yönetimi: Context API kullanılarak hazırlanan favorilere ekleme/çıkarma sistemi.

Navigasyon: Sayfalar arası akıcı geçiş yapısı.
